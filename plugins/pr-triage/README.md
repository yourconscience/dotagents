# PR Triage Plugin

This is a packaging scaffold for the dotagents `pr-triage` workflow.

Canonical sources stay in the repo:

- Skill policy: `skills/pr-triage/SKILL.md`
- GitHub MCP entry: `dotagents.yaml`
- Hook declarations: `dotagents.yaml`
- Hook runtime: `skills/pr-triage/hooks/stop.sh`
- Memory hooks: `memory/hooks/`

Do not edit this plugin as the source of truth. Update the canonical files, then refresh the package.
